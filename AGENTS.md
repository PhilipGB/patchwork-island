# Repository instructions for coding agents

This repository contains the complete product and delivery specification for Patchwork Island.

- The entry instructions are in `STARTING_PROMPT.md`.
- Read `GAME_SPEC.md`, `ART_DIRECTION.md`, `MISSIONS.json`, `IMPLEMENTATION_PLAN.md` and `ACCEPTANCE.md` before implementing gameplay.
- Treat the acceptance checklist as a release gate, not a suggestion.
- Use Godot 4.7.2 .NET / C# and implement all ten distinct missions.
- Do not substitute placeholders for gameplay or claim tests passed without executing them.
- Use `PROGRESS.md` as the durable status log, including failing tests and graphical verification gaps.
- Do not assume the PNG reference boards are authoritative for text or numbers; the written specification wins.

positioned in `Town_Preview.tscn` at the unchanged source world coordinates.

## Geography

West terrain centre (-7.25,-0.5,0), size (96.5,1,110). East centre
(72.5,-0.5,0), size (47,1,110). River x=41..49. Main roads use the 11
source `AddRoadRect` centre/size values, and replay the original slight
height offsets that suppress visual fighting.

`RallyRoadPreview.tscn` references `RallyRoad.obj`, generated by Catmull–Rom
interpolation from the original 13 source control points, width 8 m, shoulders
1.5 m. Collision for runtime use comes from `RallyRoad_Collidable.tscn`.
